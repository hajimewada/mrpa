MRPA
Multi-Resolution Prosody Analysis

A research project investigating Japanese prosody using FastSpeech2-CWT.

Goal
Determine whether:

Pitch Accent
Accentual Phrase
Downstep
Intonational Phrase
emerge naturally in CWT scale space.
